📋 구글 시트 연결 방법
  1. 1 구글 시트 상단 메뉴 → 파일 → 웹에 게시
  2. 2 '전체 문서' 와 '쉼표로 구분된 값(.csv)' 선택 후 게시 클릭
  3. 3 생성된 URL 복사 → index.html 안 SHEET_CSV_URL 에 붙여넣기
  4. 4 Netlify에 파일 재업로드 → 완료!

📢 공지사항 시트 연결

구글 시트 공지사항 탭 설정
  1. 1 구글 시트 하단 + 버튼 → 탭 이름 '공지사항' 으로 변경
  2. 2 1행 헤더: 제목, 날짜, 고정여부(Y/N), NEW여부(Y/N), 내용
  3. 3 파일 → 공유 → 웹에 게시 → '공지사항' 탭 + CSV 선택 → 게시 → URL 복사
  4. 4 NOTICE_CSV_URL 에 붙여넣기 후 Netlify 재업로드
